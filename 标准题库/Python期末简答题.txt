# 题库名称: Python期末简答题

### [简答]
1、 简述Python的特点（优缺点）。
答案: 优点：简洁、语法优美、简单易学、开源、可移植、扩展性好、类库丰富、通用灵活、模式多样、中文 支持。 缺点：执行效率不高、版本不兼容、加密性差。

### [简答]
2、 请列举出Python中的数据类型（列出8种类型得满分）。
答案: 整形，浮点型，布尔型，复数型，None类型，字符串，列表，元组，字典，集合

### [简答]
3、 简述位置参数传递、关键字参数传递、默认参数传递的区别。
答案: 位置参数传递：定义函数调用时，根据形参的位置，赋予对应的实参，受定义时形参的位置影响。 关键字参数传递：通过键-值的对应关系，清楚的对形参进行实参传递，不在受形参位置的影响。 默认参数传递：定义函数时对形参进行默认初始值，调用时可不用进行实参传递。

### [简答]
4、 简述文本文件和二进制文件的区别。
答案: 文本文件和二进制文件这2种类型的划分基于数据逻辑存储结构而非物理存储结构，文本文件专门存储问嗯字符数据，而二进制文件是人们根据计算机中数据的逻辑存储结构为文件划分的类别，用于存储图像、音频、视频、可执行文件等，这类文件不能直接使用文字处理程序正常读写。

### [简答]
5、 简述实例方法、类方法、静态方法的区别。
答案: 实例方法：创建一个实例后，通过实例名、方法名对实例方法进行调用，也可以通过实例真核对静态方法和类方法进行调用 类方法：不能访问所在类中实例的属性，只能访问所在类的属性，内部可以用cls来创建实例 静态方法：相当于一个写在类中的普通方法，内部不能创建实例，

### [简答]
6、 简述函数的定义。
答案: 函数指被封装起来的、实现某种功能的一段 代码，它可以被其他函数调用。

### [简答]
7、 简单介绍递归的定义。
答案: 递归是一个函数直接或间接调用自身的一种方法,它通常把一个大型的复杂问 题层层转化为一个与原问题相似,但规模较小的问题进行求解。

### [简答]
8、简述匿名函数与普通函数的区别。
答案: 匿名函数与普通函数主要有以下区别： （1）普通函数需要使用函数名进行标识；匿名函数不需要使用函数名进行标识。 （2）普通函数的函数体中可以有多条语句；匿名函数只能是一个表达式。 （3）普通函数可以实现比较复杂的功能；匿名函数只能实现比较单一的功能。 （4）普通函数可以被其他程序使用；匿名函数不能被其他程序使用。

### [简答]
9、 简单说明 match() 和 search() 函数的异同。
答案: match()和search()都对文本进行匹配，并在匹配成功时返回一个匹配对象，匹配失败时返回None，但match()只对文本开头进行匹配，search()可以对文本任意位置进行匹配。

### [简答]
10、 解释Python中的列表(List)和元组(Tuple)的区别，并给出一个创建列表和元组的例子。
答案: 列表是可变的数据类型，可以修改其元素；元组是不可变的数据类型，一旦创建就不能修改。例如，列表可以通过list_name = [1, 2, 3]创建，而元组可以通过tuple_name = (1, 2, 3)创建。

### [简答]
11、 解释Python中的lambda函数是什么，并给出一个使用lambda函数的例子。
答案: lambda函数是Python中的匿名函数，它可以在一行代码中定义简单的函数。例如，可以通过lambda x: x * 2定义一个将输入值乘以2的lambda函数。

### [简答]
12、 请描述Python中的字典(Dictionary)数据结构的特点，并给出一个创建字典的例子。
答案: 字典是 Python 中基于键值对存储数据的结构，特点是无序、可变、通过键快速访问值。键不可重复且不可变，值可以是任意类型。创建示例： person = {"name": "Tom", "age": 20} 。

### [简答]
13、 解释 Python 中的异常处理机制，并给出一个 try-except 语句的例子。
答案: Python 异常处理机制用于捕获和处理运行时错误。try-except 语句在 try 块中执行可能引发错误的代码，except 块用于捕获特定异常并处理。例如： try: result = 10 / 2 except ZeroDivisionError: print("除数不能为零") else: print(result)
